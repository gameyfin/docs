# Game requests

Open **Administration → Game Requests** to review requests and configure who can submit them.
Requests let users suggest games for your library; they do not automatically obtain or install game files.

Requests are enabled by default. Guest submissions are disabled.
Each user may have **10** pending requests by default; set the limit to **0** for unlimited requests.
Allow guest requests only if you intend visitors without accounts to submit requests.

See the [reference](reference.md#requests-games-enabled) for the exact settings.
