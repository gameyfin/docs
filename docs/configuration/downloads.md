# Downloads

Install and enable a [download provider](plugins.md) before expecting games to be downloadable.
For browser downloads, install Direct Download from the marketplace.

Open **Administration → Downloads** for download management and bandwidth settings.
Per-user bandwidth limiting is experimental and disabled by default.
When enabled, the default cap is **100 Mbps** per user. Mbps means megabits per second, not megabytes per second.
Provider-specific transfer methods may have their own limitations; consult the plugin's documentation.

See the [reference](reference.md#downloads-bandwidth-limit-enabled) for bandwidth settings.
